# Around The U.S. — Sprint 19

Aplicación full stack para registrar usuarios, editar el perfil y compartir tarjetas con imágenes. Permite agregar tarjetas, eliminarlas y dar o quitar «me gusta».

## Estructura

- `frontend/`: aplicación React creada con Vite.
- `backend/`: API con Express y MongoDB.

## Desarrollo local

1. Iniciar MongoDB.
2. En `backend/`, ejecutar `npm install` y `npm run dev`.
3. En `frontend/`, ejecutar `npm install` y `npm run dev`.
